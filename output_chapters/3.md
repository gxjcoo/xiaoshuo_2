# 第 3 章 咸鱼翻身与仙子的秘密

"快！把他抬到静室去！"戴不凡的声音在耳边忽远忽近，陈小闲感觉自己像条被扔上岸的咸鱼，被人七手八脚地抬着走。

"等等！"付源一把拦住抬担架的道童，"他这症状分明是走火入魔，你们知妄观就这么对待天才？"

陈小闲在昏迷中抽搐了一下，心想这货倒是挺讲义气——如果忽略"天才"这个让他吐血的称呼的话。

"孟公子有所不知。"戴不凡搓着手解释，"忆苦灵根每次突破都需要经历'痛定思痛'的过程，你看他这七窍流血的样子，多么标准的顿悟前兆啊！"

"......"付源盯着陈小闲嘴角不断涌出的血沫，陷入了沉思。

"让开。"清冷的女声突然插入，人群自动分开一条路。清瑶仙子踏空而来，素手轻挥，陈小闲便漂浮起来，"我带他去药庐。"

南宫傲在人群中嫉妒得眼睛发红："凭什么..."

"凭我是首席。"清瑶仙子头也不回地丢下一句，白色身影转瞬消失在云端。

陈小闲再次醒来时，发现自己泡在一个大木桶里。桶里是墨绿色的药汤，散发着浓郁的苦味。他试着动了动手指，惊喜地发现系统面板还能调出来：

【紧急维护完成】
【新增功能：咸鱼商城（限时特惠）】
【当前修为：练气一层（伪）】
【备注：由于宿主险些违规恋爱，系统已自动安装"钢铁直男"补丁】

"......"陈小闲盯着那个刺眼的"伪"字，突然很想把系统拖出来暴打一顿。

"醒了？"屏风后转出个端着药碗的少女，杏眼圆脸，腰间挂着药囊，"把这碗'九转还魂汤'喝了。"

陈小闲警惕地往后缩了缩："能问下成分吗？"

"百年蜈蚣须、千年蝙蝠粪，还有..."少女掰着手指数到一半，突然狡黠一笑，"骗你的啦！就是普通黄连汤加蜂蜜。"

陈小闲松了口气，接过碗一饮而尽——然后整张脸皱成了菊花。这特么比系统还坑！

"噗嗤。"少女笑出声来，"我叫桃夭叶，药庐学徒。清瑶师姐说等你醒了，把这个给你。"

她递来一块留影石。陈小闲注入微弱的灵力，空中立刻浮现出清瑶仙子的虚影：

"明日辰时，后山试剑崖。"

影像戛然而止。桃夭叶好奇地凑过来："师姐从不对男弟子另眼相待，你到底是什么人啊？"

"一个倒霉的穿越者..."陈小闲小声嘀咕。

"什么？"

"没什么。"陈小闲突然想起什么，"对了，和我一起的那个孟..."

"哦，那个火灵根天才啊！"桃夭叶眼睛一亮，"被赤霄峰主收为亲传弟子啦！现在全宗门的师姐师妹都在打听他的生辰八字呢！"

陈小闲嘴角抽搐，系统面板突然弹出警告：

【检测到恋爱话题！】
【灵力紊乱预警：10%...20%...】

"打住！"他猛地站起来，药汤哗啦啦洒了一地，"我突然想起还有急事！"

桃夭叶目瞪口呆地看着他裹着床单夺门而出。

夜色如墨，陈小闲鬼鬼祟祟地摸回临时宿舍。推开门，却见付源正翘着二郎腿坐在他床上，手里把玩着一块火焰形状的玉佩。

"哟，'忆苦灵根'醒啦？"付源挑眉，"听说你在药庐表演了出浴狂奔？"

陈小闲黑着脸找衣服穿："你怎么在这？"

"来给你送这个。"付源抛来一块玉牌，"内门弟子凭证。虽然你资质差了点，但戴师兄力荐，长老们勉强同意让你当个记名弟子。"

陈小闲接过玉牌，触感冰凉。系统突然叮咚一声：

【主线任务更新：查明"天缺之体"真相】
【提示：清瑶仙子好感度+5（当前 5/100）】

"对了。"付源凑过来压低声音，"你那个灵根...真的要靠回忆痛苦修炼？"

陈小闲看着对方真诚的眼神，突然良心一痛："其实..."

"我懂！"付源突然拍他肩膀，"就像我们赤霄峰的《焚心诀》，越练越痛苦，但威力越大！"他掏出一本小册子塞给陈小闲，"这是我偷偷抄的入门篇，你参考下。"

陈小闲翻开第一页，只见上面写着："欲练此功，必先自宫。"

"......"

"拿错了！"付源慌忙抢回去，又掏出另一本，"这本才是！"

新册子封面上写着《火球术从入门到精通》。陈小闲感动之余，突然想到一个问题："我是水灵根啊。"

"啊？"付源愣住，"你不是忆苦灵根吗？"

两人面面相觑。系统适时弹出提示：

【单身灵根兼容性：可模拟任意属性（威力减半）】
【特别提醒：水系法术需配合"孤寡青蛙"手印】

陈小闲默默合上册子："谢谢，我会好好研究的。"

次日拂晓，陈小闲按约来到后山。试剑崖如刀削般陡峭，清瑶仙子正立于崖边，白衣猎猎。

"来了。"她转身，目光如剑，"演示你的灵根。"

陈小闲硬着头皮掐诀——其实是昨晚刚学的火球术。随着"孤寡青蛙"手印完成，掌心"噗"地冒出团蓝色小火苗，颤巍巍地晃了两下就灭了。

清瑶仙子眉头微蹙："再来。"

这次陈小闲铆足全力，火苗终于有鸡蛋大小，但颜色变成了诡异的粉红色。

"......"清瑶仙子沉默片刻，突然并指成剑点向陈小闲眉心。一股凌厉的灵力长驱直入，直奔他空荡荡的丹田。

【警告！外来入侵！】
【系统防御启动：咸鱼护体！】

陈小闲丹田处突然浮现出一条咸鱼虚影，张嘴咬住了清瑶仙子的灵力。场面一度十分尴尬。

"果然。"清瑶仙子收回手，"你没有灵根。"

陈小闲后背发凉，正想狡辩，却听她继续道："三十年前，我也没有。"

晨光中，清瑶仙子解开右手绷带，露出手腕内侧一道狰狞的疤痕："这是天缺之体的标记。修仙界认为我们是被天道抛弃的人。"

陈小闲心跳加速："那您是怎么..."

"偷天换日。"清瑶仙子目光灼灼，"我在古籍中找到方法，用剑意强行开辟伪灵根。虽然过程凶险，但..."她指尖轻弹，一道剑气呼啸而出，将十丈外的巨石劈成两半，"值得。"

陈小闲咽了口唾沫。系统突然疯狂闪烁：

【紧急任务：拜师清瑶】
【奖励：伪灵根升级包】
【失败惩罚：永久性 ED】

这破系统是跟"单身"杠到底了是吧？！

"仙子。"陈小闲扑通跪下，"请收我为徒！"

清瑶仙子微微颔首："可以。但有个条件——"

她话未说完，远处突然传来急促的钟声。两人同时转头，只见主峰方向升起一道赤色烟柱。

"敌袭？"陈小闲紧张起来。

清瑶仙子却露出古怪表情："是收徒大典...付源被赤霄峰主强行收徒，正在闹绝食。"

陈小闲："......"

这个修仙界是不是哪里不太对？
