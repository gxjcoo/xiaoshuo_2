# 第十三章 夜袭

月黑风高，正是杀人夜。

叶长青的实验室中，监控设备突然亮起红灯。有人正在靠近。

"来得真快。"他冷笑一声。才过了三天，永恒阁就按捺不住了。

"师兄......"张小山紧张地问道。

"别怕，我们早有准备。"叶长青启动了实验室的防御系统。这是他最新研发的科技法阵，结合了现代安防技术和修真阵法。

很快，外面传来轻微的响动。三道黑影悄无声息地潜入院中，动作娴熟，显然是高手。

叶长青通过监控看得一清二楚。这些人身上都带着特殊的隐匿法器，普通修士根本发现不了他们。

"准备。"他对张小山使了个眼色。

黑影们来到实验室门前，其中一人取出一件法器，对着门锁一照。门锁无声无息地打开了。

"太轻松了。"为首的黑影低声说道。

但就在他们踏入实验室的一瞬间，叶长青按下了开关。

"滋滋滋......"

一道无形的能量网瞬间笼罩整个房间。三个黑影顿时僵在原地，动弹不得。

"欢迎光临。"叶长青从暗处走出，"不知三位深夜来访，有何贵干？"

"你......"黑影们这才发现不对劲。他们引以为傲的隐匿法器完全失效了，身上的法力也被封住。

"别费劲了。"叶长青打开实验室的灯，"这个能量场专门克制你们的装备。"

灯光下，三个黑影的样貌显露出来。全都是永恒阁的精英弟子。

"永恒阁的手段，就这？"叶长青摇摇头，"我还以为会来点厉害的角色。"

"你早就知道我们要来？"为首的黑衣人惊讶地问。

"不然呢？"叶长青从他们身上搜出几件法器，"这些东西就是永恒阁的手笔吧？科技含量不错。"

黑衣人脸色大变："你怎么知道......"

"呵呵。"叶长青没有回答，而是仔细检查着缴获的装备。这些法器中都藏着现代科技的元件，看来永恒阁的研究已经有了不小的进展。

"你们回去告诉赵明。"他淡淡地说，"想要我的技术，就拿点真本事来。这种小把戏，太让人失望了。"

"你......"黑衣人还想说什么，突然感到一阵眩晕，昏了过去。

叶长青收起能量场，让张小山把三人扔到了城外。他们醒来后，只会以为自己遭到了强力法术的攻击，不会记得任何细节。

"师兄，他们还会来吗？"张小山问道。

"当然。"叶长青若有所思，"这只是第一波试探。永恒阁想要的，可不只是我的科技修真体系。"

他打开电脑，调出了最新的研究数据："他们真正想要的，是这个。"

屏幕上显示着一个复杂的能量模型。这是他根据青铜门的能量特征研究出来的。如果计算正确，这个模型可以实现两个世界的能量自由转换。

"下一步，他们可能会来硬的。"叶长青说道，"我们要加快进度了。"

他看了看时间，距离下一次穿越还有两个时辰。他要在这段时间内，完成新一代能量转换装置的改进。

永恒财团既然按捺不住了，那就陪他们玩玩。

"张小山，去准备材料。今晚我们要熬夜了。"

【这一章完】
