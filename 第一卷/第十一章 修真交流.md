# 第十一章 修真交流

云霄城，修真界最大的交易中心之一。

这次的修真交流会就在这里举行。来自各大门派的精英弟子齐聚一堂，展示各自的修炼心得。

"叶师兄，那边好像是永恒阁的人。"张小山小声提醒道。

叶长青顺着他的目光看去。果然，在会场的一角，站着几个气质不凡的修士，胸前别着永恒标志。

"知道了。"他暗中启动了随身携带的监测设备。

很快，交流会正式开始。各派弟子轮流上台展示。有人展示新创的功法，有人展示独特的法器，各有特色。

"下面，请阴鬼宗叶长青上台。"

叶长青整理一下衣袍，从容走上高台。台下议论纷纷，显然都听说过他的"新修炼理论"。

"在下叶长青，今日要展示的是一件新型法器——太虚引。"

他取出那枚玉佩。看起来普普通通，但内里却藏着惊人的科技。

"这法器有何特别之处？"台下有人问道。

叶长青微微一笑："请看。"

他激活了太虚引。刹那间，一股奇特的能量波动扩散开来。所有人都感觉到，周围的灵力变得异常活跃。

"这是......"有人惊呼，"灵力共鸣？"

但这只是开始。叶长青又掐动法诀，太虚引开始释放储存的能量。顿时，他的修为气息暴涨，连元婴期的修士都感到一丝压力。

"不可能！"有人失声叫道，"他明明只是筑基期，怎么会有这么强的气息？"

叶长青没有解释，而是开始演示太虚引的其他功能。能量转换、灵力增幅、防御屏障......一系列展示看得台下目瞪口呆。

"精彩！"主持交流会的长老击掌赞叹，"叶小友这法器当真不凡。不知可否详细说说其中原理？"

"这......"叶长青装作为难的样子，"恕在下不能细说。这是结合祖师传承所创，其中有些关键之处......"

"理解理解。"长老连连点头。在修真界，功法法器的核心秘密向来都是不能外传的。

但叶长青注意到，永恒阁的人却露出了意味深长的表情。其中一人更是若有所思地盯着太虚引。

下台后，果然有不少人来询问详情。叶长青都是点到为止，绝不多说。

"叶道友。"一个温和的声音响起。

转身一看，是永恒阁的人。对方彬彬有礼地行了一礼："在下永恒阁赵明。叶道友的法器很是不凡，不知可否详谈？"

"赵道友客气。"叶长青拱手回礼，"不过恕我现在还有要事，改日再聊。"

"那就改日再会。"赵明也不强求，转身离去。

但叶长青知道，永恒财团已经盯上了自己的"法器"。这正是他想要的效果。

"张小山。"他低声吩咐，"派人盯着永恒阁的人。"

这次交流会，表面上是展示实力，实际上却是他布下的一个局。他要引永恒财团上钩，看看他们到底想要什么。

【这一章完】
