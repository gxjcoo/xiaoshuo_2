# 第十九章 最后准备

"所有设备都准备好了吗？"

实验室中，叶长青正在检查最后的装备。距离永恒阁的"双界大典"只剩三天，他们必须做好万全准备。

"都ready了。"小王通过通讯器回答，"现实世界这边的装置已经就位。"

"修真界这边也差不多了。"张小山补充道，"那些改良版的'法器'已经分发给可靠的弟子。"

叶长青点点头，走到一个巨大的显示屏前。屏幕上显示着两个世界的地图，其中标注着许多红点。

"这些都是永恒财团的能量节点。"他指着地图说，"他们在两个世界同时建立了一个巨大的能量网络。"

李青研究着数据："这种能量分布......他们是想在两界之间建立永久性通道！"

"没错。"叶长青说道，"但他们没想到，我们可以利用这个网络反制他们。"

他打开了一个特殊的程序。这是他根据两界能量规律研发的控制系统。

"一旦他们启动仪式，能量网络就会激活。"他解释道，"到时候，我们就可以用这个系统干扰能量流向。"

"但是，"李青提醒道，"这样会不会导致能量失控？"

"所以我们还需要这个。"叶长青取出一个装置，"我管它叫'能量中和器'。"

这是他的最新发明，融合了现代科技和修真术法的精华。可以将失控的能量重新引导，变成稳定的能量流。

"关键是时机。"他在地图上画了几个点，"我们要在他们仪式进行到这一步时出手。"

"那我们怎么潜入进去？"张小山问道，"永恒阁肯定戒备森严。"

"不用潜入。"叶长青露出神秘的笑容，"我们会光明正大地进去。"

他拿出一份请帖："永恒阁已经给阴鬼宗发来了邀请。"

"这不是个陷阱吗？"

"当然是陷阱。"叶长青说道，"但这正是我们需要的。他们越是注意我们，就越注意不到其他地方的布置。"

他调出了一份详细的计划书："小王负责现实世界的能量节点，张小山你带队控制修真界的关键位置，李青作为能量调节的核心......"

"那师兄你呢？"

"我？"叶长青笑了笑，"我要去会会永恒财团的幕后主使。"

他打开了一个加密文件："根据调查，永恒财团的真正掌控者也有两个世界的身份。而且......"

屏幕上显示出一张古老的画像，赫然是阴鬼宗的一位祖师！

"原来如此！"李青恍然大悟，"难怪他们对阴鬼宗的传承这么感兴趣。"

"是啊。"叶长青若有所思，"这一切恐怕都是一个计划，从几百年前就开始了。"

他关上电脑，看着窗外的月光："但是这次，他们的如意算盘要落空了。"

"都去准备吧。"他下达最后的指令，"记住，一旦行动开始，就没有回头路了。"

众人离开后，叶长青独自站在实验室中。他取出那枚玉佩——太虚引。

"是时候展现你真正的力量了。"

【这一章完】
